# stage

**If you perform:** Blender scenes, caches, and exports for visuals that sit beside the DJ stack — kept out of ix so GPL tooling does not mix with the Apache crate code. Inception goal: reusable stage geometry and renders, not another DAW.

Blender tools that stay out of [ix](https://github.com/ixamal/ix). Scenes, caches, and exports.

**GPL-3.0-or-later.** A script that imports `bpy` belongs here. ix stays Apache 2.0. This repo does not import ix. ix does not import this repo. [grid](https://github.com/ixamal/grid) is the DJ repo, and the two do not depend on each other.

Each tool here builds and runs on its own. Blender is GPL-2.0-or-later. Tools in this repo are released under GPL-3.
